# Source data

This directory contains compact source data used for the summary panels in the manuscript.

- `Fig2_mass_sweep.csv` — mass-dependent FLRW separation measures.
- `Fig3_hierarchy.csv` — finite source-jet matching errors and the next unmatched jet.
- `Fig4_convergence.csv` — direct-versus-memory convergence summary.
- `Fig4_identifiability_summary.csv` — matched-moment accuracy, kernel separation and metric-transfer separation for the response-identifiability example.
- `Fig5_tomography_summary.csv` — synthetic reconstruction errors, selected regularization strengths and inverse conditioning.

The longer time-series and profile data underlying the figures are generated deterministically by the scripts in `code/` and are supplied as Source Data with the manuscript.
