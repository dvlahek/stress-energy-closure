# Source data

This directory contains compact source data used for the manuscript figures and numerical controls.

- `Fig2_identifiability_summary.csv` — matched-moment accuracy, kernel separation and metric-transfer separation for the response-identifiability example.
- `Fig3_tomography_summary.csv` — synthetic reconstruction errors, selected regularization strengths and inverse conditioning.
- `Fig4_mass_sweep.csv` — mass-dependent FLRW separation measures.
- `Fig5_hierarchy.csv` — finite source-jet matching errors and the next unmatched jet.
- `ExtendedData_direct_memory_convergence.csv` — direct-versus-memory convergence summary.

Full time-series and profile data are generated deterministically by the scripts in `code/` and are supplied as Source Data with the manuscript.
