# Source data

This directory contains compact source data used for the manuscript figures and numerical controls.

- `Fig1_prediction_summary.csv` — peak complex-response, amplitude and phase separations for the stress-energy-matched prediction example.
- `Fig2_identifiability_summary.csv` — matched-moment accuracy, kernel separation and metric-transfer separation for the response-identifiability example.
- `Fig3_tomography_summary.csv` — representative synthetic reconstruction errors, regularization strengths and inverse conditioning.
- `Fig3_noise_sweep.csv` — reconstruction errors for the finite-data response-noise sweep.
- `Fig4_mass_sweep.csv` — mass-dependent FLRW separation measures.
- `Fig5_hierarchy.csv` — finite source-jet matching errors and the next unmatched jet.
- `ExtendedData_direct_memory_convergence.csv` — direct-versus-memory convergence summary.

The prediction values are dimensionless proof-of-principle outputs for the validation coupling used in the manuscript and are not observational sensitivity forecasts. Full frequency-series, time-series and profile data are generated deterministically by the scripts in `code/` and are supplied as Source Data with the manuscript.
